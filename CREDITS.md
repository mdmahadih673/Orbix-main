## Orbix Fork

**Orbix** extends Bloom with additional views, capabilities, and controls for Windows desktop power users:
- **Power View**: Desktop session controls (Lock, Sleep, Restart, Shutdown) with safety confirmations.
- **Wallpaper View**: Dynamic desktop wallpaper browser, thumbnail cache, and wallpaper switcher via Windows Shell APIs.
- **Apps View**: Full launcher search across installed desktop apps, Store packages, and indexed files/folders with quick dock pinning.
- **Media View**: User-attached media application shortcuts, multi-session GSMTC controller, and playback switcher.
